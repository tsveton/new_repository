# Список знакомых git-команд

| Команда | Описание |
|---|---|
| `git init` | Инициализировать новый локальный репозиторий |
| `git clone <url>` | Клонировать удалённый репозиторий |
| `git status` | Показать состояние рабочей директории и индекса |
| `git add <файл>` | Добавить файл в индекс (staging area) |
| `git add .` | Добавить все изменённые файлы в индекс |
| `git commit -m "msg"` | Создать коммит с сообщением |
| `git commit -a -m "msg"` | Добавить в индекс и создать коммит |
| `git log` | Посмотреть историю коммитов |
| `git branch <name>` | Создать ветку |
| `git checkout <name>` | Перейти на существующую ветку |
| `git checkout -b <name>` | Создать ветку и переключиться на неё |
| `git push origin <branch>` | Отправить изменения на удалённый репозиторий |
| `git pull` | Загрузить состояние удалённого репозитория |
| `git diff` | Показать различия между версиями файлов |
| `git merge <branch>` | Слить указанную ветку в текущую |
